# Riwayat konfigurasi aplikasi

`app_config_5_6_development.json` adalah salinan konfigurasi pengembangan yang digunakan ketika implementasi hingga Subbab 5.6 didokumentasikan. Nilainya mencakup ROI 0,80, blur 35, luminansi 45–220, CLAHE aktif 2,0/4×4, confidence 0,80, window 1.500 ms, minimum 3, dan analysis FPS 3.

Berkas operasional `app/src/main/assets/app_config.json` kemudian diperbarui setelah kalibrasi 5.7.2. Penyimpanan riwayat ini mencegah konfigurasi pengembangan pada uraian 5.6 tercampur dengan konfigurasi statis hasil kalibrasi.
